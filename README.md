# AI Mermaid 다이어그램 생성기

텍스트를 입력하면 AI가 내용을 분석하여 Mermaid 다이어그램을 자동으로 생성하고 시각화해주는 단일 파일 웹 앱입니다.

---

## 빠른 시작

별도 설치 없이 `index.html` 파일을 브라우저에서 열면 바로 실행됩니다.

```
1. index.html 브라우저에서 열기
2. Claude 또는 OpenAI API 키 입력
3. 분석할 텍스트 입력
4. 다이어그램 유형 선택 (최대 3개)
5. 생성 버튼 클릭
```

---

## 주요 기능

### AI 공급자 선택

Claude (Anthropic)과 OpenAI 두 가지를 지원합니다.

| 공급자 | 모델 | API 키 형식 |
|---|---|---|
| 🟣 Claude (Anthropic) | claude-haiku-4-5-20251001 | `sk-ant-...` |
| 🟢 OpenAI | gpt-4o-mini | `sk-...` |

API 키는 브라우저 메모리에만 저장되며 탭을 닫으면 사라집니다.

### 다중 선택 및 동시 생성

최대 3개의 다이어그램 유형을 선택하여 한 번에 생성할 수 있습니다.

- 카드 클릭 시 선택 순서대로 ① ② ③ 번호 뱃지 표시
- 3개 선택 시 나머지 카드 자동 비활성화
- `Promise.allSettled` 병렬 처리 — 순차 생성과 속도 거의 동일
- 하나가 실패해도 나머지 결과 정상 표시

---

### 줌 컨트롤

각 결과 카드 상단 툴바에서 다이어그램 크기를 조절합니다.

```
[ − ]  100%  [ + ]  [ ↺ 원래크기 ]  [ ↔ 맞춤 ]          [ ⛶ 전체화면 ]
```

| 버튼 | 기능 |
|---|---|
| `−` / `+` | 25% 단위 축소 / 확대 (범위: 25% ~ 400%) |
| `↺` | 100% 원래 크기로 복원 |
| `↔ 맞춤` | 컨테이너 너비에 맞게 자동 스케일 |
| `⛶` | 전체화면 모달로 열기 |

---

### 전체화면 모달

`⛶` 버튼으로 다이어그램을 화면 전체로 펼쳐 볼 수 있습니다.

- 열릴 때 자동으로 너비 맞춤 적용
- 모달 내 독립적인 줌 컨트롤
- 닫기: `✕ 닫기` 버튼 / 배경 클릭 / `ESC` 키

---

### 다크 / 라이트 모드

헤더 우측 `☀️ / 🌙` 버튼으로 전환합니다.

- 최초 접속 시 시스템 설정 자동 감지 (`prefers-color-scheme`)
- `localStorage`에 저장 — 새로고침 후에도 유지
- CSS 변수 기반으로 부드럽게 전환 (0.25s)

---

### 오류 자동 수정

렌더링 실패 시 AI가 오류 메시지를 분석하여 코드를 자동으로 수정합니다 (최대 2회).

```
렌더링 실패 → AI 코드 수정 → 재렌더링 (최대 2회)
            → 실패 시 코드 탭에서 수동 확인 안내
```

---

### 비용 최적화 (Claude 전용)

**Prompt Caching** 이 적용되어 있습니다.

- 시스템 프롬프트에 `cache_control: { type: "ephemeral" }` 지정
- 같은 세션 내 반복 호출 시 해당 토큰을 **원가의 10%** 만 과금
- 자동 수정 재시도, 동일 유형 재생성 시 캐시 히트 발생

> Batch API (50% 할인)는 실시간 인터랙티브 앱 특성상 적용하지 않았습니다.

## 주의사항

- API 키는 브라우저 네트워크 탭에 노출될 수 있습니다. 프로덕션 환경에서는 백엔드 프록시 구성을 권장합니다.
- Mermaid 캐시 최소 단위(1,024 토큰)에 따라 짧은 프롬프트는 캐시되지 않을 수 있습니다.
- OpenAI는 자동 프롬프트 캐싱을 지원하므로 별도 설정이 필요 없습니다.
