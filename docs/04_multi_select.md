# 다중 선택 및 동시 생성

## 개요

한 번의 생성 요청으로 최대 3개의 다이어그램을 동시에 만들 수 있습니다.  
API 호출을 병렬로 처리하여 순차 생성 대비 속도 차이가 거의 없습니다.

## 사용 방법

1. 유형 카드를 클릭하여 선택 (선택 순서대로 ① ② ③ 번호 뱃지 표시)
2. 최대 3개까지 토글 가능 — 이미 선택된 카드를 다시 클릭하면 해제
3. 3개 선택 시 나머지 카드 자동 비활성화 (흐려짐)
4. **✨ 다이어그램 N개 동시 생성하기** 버튼 클릭

## UI 상태 변화

```
선택 0개 → "유형을 선택하세요 — 0 / 3 선택됨"          버튼 비활성
선택 1개 → "1개 선택됨 — 추가 선택하거나 생성하세요"    "✨ 다이어그램 생성하기"
선택 2개 → "2개 선택됨 — 추가 선택하거나 생성하세요"    "✨ 다이어그램 2개 동시 생성하기"
선택 3개 → "3개 선택됨 (최대)"                          "✨ 다이어그램 3개 동시 생성하기"
```

## 병렬 처리 구조

```javascript
// Promise.allSettled — 하나 실패해도 나머지 결과 정상 표시
const results = await Promise.allSettled(
  selectedTypes.map(typeId => callAI([...], buildPrompt(typeId)))
);
```

- `Promise.all` 대신 `Promise.allSettled` 사용
- 개별 실패 시 해당 카드에 오류 메시지 표시, 나머지는 정상 렌더링

## 결과 표시

생성 즉시 로딩 카드가 세로로 쌓이고, 완료된 순서대로 채워집니다.

```

│ ┌─────── SVG ──────────┐   │

├─────────────────────────────┤
```

각 결과 카드는 독립적인 미리보기/코드 탭과 줌 컨트롤을 가집니다.

## 관련 전역 변수

| 변수 | 타입 | 역할 |
|---|---|---|
| `selectedTypes` | `string[]` | 선택된 다이어그램 ID 배열 (순서 유지) |
| `currentCodes` | `{ [typeId]: string }` | 생성된 Mermaid 코드 저장 |
| `zoomLevels` | `{ [typeId]: number }` | 각 다이어그램 줌 레벨 저장 |
